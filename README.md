# dohun.zip — Instagram-style fictional profile

A responsive, static Korean Instagram-inspired profile page for a fictional couple account.

## Preview locally
Open `index.html` in a browser. Photos load from Unsplash, so an internet connection is needed for the images.

## Deploy to GitHub Pages
1. Create a new repository on GitHub (for example, `dohun-instagram`).
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

All profile details and interactions are fictional demo content. The page is not affiliated with Instagram.
